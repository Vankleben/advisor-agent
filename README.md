# 导师情报与论文伴读 Agent 🎓

> 一个帮你 **找实验室、读论文、改认知、定进组路线** 的本地智能体。
> 基于 LLM Function Calling + 多层反幻觉校验——**每条结论都能溯源到原文，查不到就明说，绝不编造。**

你是否遇到过这些问题：

- 想找导师，但学院官网信息陈旧，招生状态、真实研究方向散落在个人主页、GitHub、arXiv 各处？
- 论文读了一堆，读完说不出所以然，自己的理解对不对没人帮你校对？
- 想进某个组，但不知道"这位老师缺什么样的人""我现在做的项目够不够敲门"？

这个 Agent 就是为这三种场景设计的。

---

## ✨ 功能总览

| 模块 | 干什么 | 一句话体验 |
|---|---|---|
| **M1 导师情报** | 从一句"某某大学"出发，自动导航官网→定位学院→抓师资名单→生成结构化导师卡片 | 招生信号 🟢🟡⚪、职业阶段（青年/中年/资深 + 对申请者的含义）、原文证据 |
| **M1.5 横向对比** | 全景表快速粗筛 + 2-5 人七项指标深度对比 | 打分矩阵 + 推荐结论，每分附证据 |
| **M2 导师深潜** | 自动抓取导师个人/实验室主页，产出七维度情报 | 研究轨迹漂移、实验室生态、招生意向、GitHub 工程足迹 |
| **M3 论文拆解** | arXiv 下载 → 阅读决策卡 → 七段式精读 | 原理直述不用生活比喻、概念按你的知识档案定制解释深度 |
| **M4 进组路径** | 从导师需求侧反推，结合你的技能画像，生成"敲门砖项目" | 自动做算力红线检查，标注在设备 A 还是 B 上跑 |
| **M5 思考批改** | 你提交读后思考，Agent 对照原文纠错、费曼追问、凝练成申请素材 | 不服判定可申诉复核——批改者自己也可能幻觉 |
| **M6 实时监测** | 收藏导师后，定期扫描其主页/arXiv/GitHub 变化，输出情报简报 | 附每日定时任务，注册后每天自动跑 |

## 💬 使用示例（真实对话）

启动后直接用中文提问，Agent 自动调用工具。以下都是实际跑通的用法：

### ① 找老师 —— "看看清华人工智能学院有哪些做大模型的老师"

Agent 自主导航学校官网 → 定位到学院师资页 → 自动收录并生成卡片：

```
你：帮我看看北京大学人工智能学院的老师

🔧 fetch_url(https://www.pku.edu.cn)        # 自主导航
🔧 fetch_url(http://sai.pku.edu.cn)         # 逐层深入
🔧 add_school('pkusai')                      # 收录+自动建卡
🔧 list_teachers({'site': 'pkusai'})

Agent：北大智能学院共收录 36 位老师：

| 姓名 | 职称 | 方向 | 招生信号 | 职业阶段 |
|---|---|---|---|---|
| 钟亦武 | 助理教授 | 视觉-语言学习、多模态大模型 | 🟢 | 青年 |
| 刘航欣 | 助理教授 | 机器人、具身智能 | ⚪ | 青年 |
| 朱松纯 | 讲席教授 | 计算机视觉、认知科学 | ⚪ | 资深 |
...
```

> 🟢 明确写了欢迎学生（附原文引用 + 抓取日期）；⚪ 官网无招生信息——**绝不把未知说成欢迎**。

### ② 深挖某位导师 —— "深挖俞立"

抓取其个人/实验室主页，产出七维度报告，每条结论附**逐字原文证据**：

```
🔧 advisor_deepdive({'name': '俞立'})

Agent：
【近期研究】migrasome（迁移体）相关细胞生物学研究
  证据: "The Li Yu Laboratory ... migrasome ..."  ← 来源1 个人主页

【研究轨迹】持续深耕细胞膜相关结构研究
【实验室生态】组内学生规模、毕业生去向
【招生意向】...
【GitHub 足迹】主页未提及，如实标注"无信息"

✅ 反幻觉校验：全部引句在原文中逐字命中
```

```
🔧 deep_compare({'names': ['俞立', '王童']})

Agent：
| 指标 | 俞立 | 王童 |
|---|---|---|
| 方向匹配度 | 3/5（细胞生物学，计算成分低） | 5/5（AI+生物结构） |
| 招生信号 | ⚪ 1/5 | 🟢 4/5 |
...

总结论：主攻王童（AI4Science 与你的兴趣和 ESM-IF1 经历高度匹配），俞立作为备选。
```

### ④ 论文精读 —— 从检索到精读的完整链路

```
你：查一下 Yinpeng Dong 近期的论文
🔧 search_papers({'author_en': 'Yinpeng Dong'})     # ⭐ 标出末位作者=导师主导

你：第 7 篇先出个决策卡
🔧 paper_decision({'arxiv_id': '2606.09669v2'})
Agent：定位：代表作 / 匹配度：中 / 建议：速读 / 前置缺口：无

你：好，精读这篇
🔧 deep_dive({'arxiv_id': '2606.09669v2'})
Agent：[七段式拆解：解决目标 → 背景 → 实验设置 → 方法流程
        → 概念解释（按你的档案：KV cache 一笔带过，新概念讲透）
        → 结果与局限 → 复现可行性（设备B 可跑，约需 X GB 显存）]

⚠️ 校验发现 2 条引句未在原文命中，已标注，请注意
```


## 🚀 快速开始

```bash
git clone <this-repo>
cd advisor_agent

# 依赖
pip install openai requests beautifulsoup4 pymupdf

# 配置 API（config.py 已被 .gitignore 排除）
```

## 🛡️ 核心设计：三层反幻觉校验

这个项目最有意思的地方——**不信任 LLM 的输出，只信任原文**：

| 校验层 | 机制 |
|---|---|
| 卡片层 | 每条 evidence 去空白归一化后必须在官网原文中逐字命中；个人主页 URL 必须来自详情页外链列表（防止 LLM 凭记忆编造主页） |
| 论文层 | 精读中所有引句归一化后必须在论文全文中找到（免疫 PDF 换行/连字符伪影）；未命中的**如实标注为可疑** |
| 深潜层 | 每条情报的证据必须在其标注的来源编号原文中命中；来源编号越界也报警 |

实测效果：精读一篇论文时 LLM 改写了原文句子，校验层立即抓出来标红；
批改模块甚至提供了**申诉通道**——因为批改者自己也可能幻觉。

其它设计决策：

- **算力红线硬约束**：进组建议内置双档硬件档案（设备A 核显 ≤3B 量化 / 设备B RTX3060 可 LoRA），超红线方案直接不生成；
- **JS 动态页兜底**：官网名单是 XHR 异步加载时（如复旦），自动降级 Chrome headless 渲染再抓取；
- **分页合并式收录**：多页师资页按姓名合并累加，重复收录幂等；
- **同名作者防御**：arXiv 检索按研究关键词过滤归属，"Yu Li" 这种大众名不会误报成你导师的新论文。

## ⚠️ 已知限制

- 论文检索目前仅 arXiv（Scholar/DBLP 计划中）；
- 部分高校官网（如浙大、西湖）存在网络层访问限制或强 JS 渲染，需要可用网络环境；已内置 Chrome headless 兜底，但不保证所有站点可达；
- LLM 输出质量依赖所用模型（默认 deepseek-chat），反幻觉校验能拦住编造，但不能保证 100% 覆盖语义级改写；
- 单机单用户设计，无多租户/鉴权。
