## 新增：动态记忆（画像随使用自动生长）

Agent 现在有一份**会自己长大的用户画像**，而且**聊天时就能看到你**（之前只有调用分析类工具时才注入）。

### 1. 主对话 / Web 界面加载画像

系统提示中实时注入【用户画像】【最近记忆】，**每轮对话刷新**——画像一更新，下一句就生效。

实测（无需任何工具调用，直接回答）：

```
你：我做过哪些项目？
Agent：| 熊类行为与个体识别 | YOLO11 迁移学习，mAP50 0.716→0.803 … |
       | ESM-IF1 蛋白质逆向折叠 | 序列恢复率 45.8%，代码开源 … |
       | 导师情报与论文伴读 Agent | 22 个工具、三层反幻觉校验 … |
```

### 2. 自动沉淀（无需你操作）

| 触发 | 自动写入 |
|---|---|
| M3 精读论文 | 论文涉及的「档案外新概念」→ 加入「在学」列表 |
| M4 进组分析 | 「可快速补齐」的技能 → 加入「在学」列表 |
| M5 思考批改 | 事件留痕（事实错误本就沉淀到错误模式库） |

### 3. 主动记忆 —— 说一句就记住

新增两个工具（工具总数 20 → **22**）：

```
你：记住：我最近在学 Rust 和 分布式训练
🔧 remember(text='Rust', category='skill_learning')

你：你记得我什么？
🔧 show_profile()   → 返回完整画像 + 近期记忆时间线
```

### 4. 可审计、可回退

- 所有写入带**事件时间线**（`archive/memory_log.json`），标注日期与来源
- 只增不减、自动去重（已掌握的概念不会重复进「在学」）
