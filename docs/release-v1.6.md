## 解决的问题

之前 `deep_dive` / `paper_decision`（论文精读）**只能处理 arXiv 论文**——下载路径写死了 arXiv。
于是出现断点：论文能查到了（Europe PMC / 实验室官网），但**点进去精读不了**。

## 新增：论文全文多级获取（`fetch_fulltext`）

论文精读现在支持**四种**全文来源，按可用性自动尝试：

| 途径 | 说明 | 适用 |
|---|---|---|
| **实验室官网 PDF** | Publications 页的 `[PDF]` 直链，直接下载 | PI 自维护，命中率最高（实测某实验室 10 篇有 PDF） |
| **DOI → OpenAlex** | 自动查询开放获取副本（OA）并下载 | 开放获取的期刊论文 |
| **PMC 全文** | Europe PMC 全文 XML | 有 PMC 编号的论文 |
| **本地 PDF** | 你手动下载的 PDF 路径 | 前三条都失败时的兜底 |

### 精读流程（新）

```
search_papers（三源检索）
  → 论文列表直接带 arxiv_id / doi / pdf 字段
  → arXiv 论文：直接 paper_decision → deep_dive
  → 其他论文：fetch_fulltext(pdf 或 doi) 拿 paper_id
              → paper_decision → deep_dive
```

### 拿不到全文怎么办（如实处理）

**非开放获取论文会明确报错**，并给出替代建议（实验室官网 / 作者主页 / 学校图书馆），
绝不编造论文内容——这延续项目的反幻觉原则。

## 防幻觉细节

- 官网 PDF 链接提取做了**双重校验**：LLM 匹配 + 链接白名单（编造的 PDF 链接直接丢弃）
- 全文下载支持 SSL 证书过期降级（很多实验室网站证书年久失修）
- 扫描版图片 PDF 会明确报"无法提取文字"，而不是返回空内容

## 实测

| 场景 | 结果 |
|---|---|
| 实验室官网 PDF（Nature 2020） | 下载解析 **112603 字符**全文 → 决策卡生成正常 |
| OA DOI（10.1038/s41586-020-2179-y） | OpenAlex 找到 nature.com PDF → 50970 字符 |
| 非 OA DOI | 明确报"未找到开放获取全文" + 替代建议 |
| 工具总数 | 19 → **20** |
