# 抓取避坑总结（2026-09-25 全库采集复盘）

8 校 → 15 站点、1414 张卡片的采集中踩过的坑，按"症状 → 根因 → 下次的硬规则"沉淀。
新增采集任务前**先读这份**。

## 一、找错页面（本次最大的错误来源）

| 症状 | 根因 | 硬规则 |
|---|---|---|
| 上科大生科 80 人只有姓名、被用户纠正 3 次 | 爬了 `szdw/list*` **新闻式名单**，真正的官方目录在"教职员工→教授"栏目 | **开爬前先抓学院首页，把导航里所有师资类栏目列出来逐一比对**；确认"当前页面是不是本站唯一权威名录"再动手。新闻列表（带发布日期）几乎从来不是名录 |
| 同一学院不同栏目数据完整度天差地别 | 生命学院 vs 生物医学工程学院是**两个站、两套模板** | 先确认目标实体（学院/系/学部）的边界和站点归属，拿不准先问用户"你说的是 A 还是 B" |

## 二、看不见的正文（静态抓取的盲区）

| 症状 | 根因 | 硬规则 |
|---|---|---|
| slst 目录静态 HTML 里 `<ul class="cols_list">` 是空的 | 名录由 JS/XHR 填充 | **静态抓到 0 条时，不要下"官网没有内容"的结论**。查三样：① 空容器+script；② `$.ajax/url=` 接口；③ 都没有就走 `web_fetch.render_url` 渲染模式（仓库已有先例：pkuais） |
| 南科大 A-Z 页 requests/headless 都提取 0 | 内容在 `POST /index.php?ajax=users` 接口里 | 空页先找 XHR 接口再解析，比渲染快且稳 |
| 西湖 agent 盲猜 106 个 URL 全失败 | SPA + JS 跳转链（`window.location` 链式跳转） | **禁止 agent 盲猜 URL**。我方先 `curl` 看跳转链/找 `xxx.json` 数据文件（西湖最终解法：`Our_Faculty/json_401.json` 全量 118 人） |
| 一个正则打天下，南科大 `<p>` 里带 `<br>` 解析全挂 | 用一个样本写的 regex 脆弱 | 解析前**抽 2-3 个不同页面**对比结构差异；正则失败率 >0 时回头看样本是不是同构 |

## 三、详情链接与缓存

| 症状 | 根因 | 硬规则 |
|---|---|---|
| 上交 208 人的"详情页"全指向同一个栏目页 | LLM 抽取把外层包装链接当成了个人页链接 | enrich 后**必须质检**：`detail_url` 唯一数应≈人数；卡片 `research_interests` 非空率是第二道闸（本次靠这张质检表抓到 4 个站的问题） |
| 改了 detail_url 重跑 enrich 没生效 | `enrich_faculty` 有"续传：已有 N 条成功记录，跳过"缓存 | **改动源数据后，派生缓存必须一起删**：`faculty_{site}_enriched.json` + `cards_{site}.json` 再重建 |
| 卡片数 > 人数（浙大 210 vs 86） | 跨页合并时人名大小写/变体未归一 | 合并后按 `casefold(name)` 去重再用 |

## 四、驱动 sub-agent（main.py）的坑

| 症状 | 根因 | 硬规则 |
|---|---|---|
| 收藏动作丢失、任务"话说一半停了" | function-calling 循环 10 轮上限**静默耗尽** | 已修：上限 30 轮 + 耗尽警告（commit 9762d8e）。驱动时盯日志里的"轮上限"告警，出现就发"继续" |
| 440s 预算把 `add_school` 腰斩 | `add_school` 内部 = crawl(300s)+enrich(900s)+batch(900s)，最坏 35 分钟 | 单校预算 ≥1500s；或**拆开直接跑** `universal_crawl.py → enrich_faculty.py → batch_cards.py`（确定性、无轮数限制） |
| FIFO 驱动 stdin 早闭 | Git Bash 环境 FIFO 不可靠 | 用 Python `subprocess.Popen(stdin=PIPE)` 驱动（`drive_one.py` 模板），轮询输出见 `Agent：` 再发 `quit` |

## 五、判断纪律（用户纠正了 3 次的根因）

1. **单样本不外推**：白芳一页是空的 ≠ 全站没内容；抽样必须跨栏目、跨条目 ≥3 个。
2. **"抓不到"≠"不存在"**：三连问——找对栏目了吗？静态渲染骗了我吗？有 API/JSON 没找吗？
3. **agent 报告要交叉验证**：agent 说"官网未提及"时，先自己 curl 一个页面验一验再采信。
4. **优先用仓库已有资产**：`SITES` 注册表里的确定性适配器（thumed/thubme/pkubio/wlls…）和 render 模式是现成的，开新站前先 `grep tools/crawl_faculty.py`。
