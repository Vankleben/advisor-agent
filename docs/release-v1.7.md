## 解决的问题

查一位清华 CS 老师（AI Agent 方向）的论文时**全军覆没**：

| 源 | 结果 |
|---|---|
| arXiv | 429 限流，0 条 |
| Europe PMC | 13 条，**全是同名学者**（生物医学/材料领域） |
| 实验室官网 | 无 Publications 页 |

根因有三层：**① 源不匹配**（Europe PMC 是生物医学库，对 CS 老师无效）；**② 重名无解**（"Wei Wang" 这类高频名，任何库按名字查都会撞一堆同名）；**③ arXiv 无重试**（一次 429 就 0 条）。

## 新增：种子论文策略（第 4 检索源）

**思路**：不按名字找人（会撞同名），而是**从一篇已知论文反查这个人**。

```
代表作（如 aiXcoder-7B）
  → OpenAlex 定位作者
  → 拉取其名下全部论文
  → 姓名级合作者交集过滤（只用跟代表作共同署名过的合作者做交叉验证）
  → 精准命中本人
```

**实测同一个案例**：

```
修复前：100+ 篇污染列表 → 无一条可用
修复后：7 篇全部真实 —— aiXcoder-7B (ICSE-SEIP 2025)、
        LongCodeU、EditSum、SkCoder (ICSE 2023)、
        Benchmarking Long-Context... (ACL 2025) 等
        每篇附"合作者印证"字段 + DOI
```

## 配套改进

- **代表作线索自动提取**：从深潜报告里自动找出代表作名称（如 `aiXcoder-7B`），放进检索结果供 Agent 直接用于重试
- **arXiv 退避重试**：429 / 5xx / 连接重置时自动重试（6→12→24 秒），不再一次失败就放弃
- **Agent 行为规则升级**：重名时的处理从「如实告知查不到」升级为「**自动用代表作线索重试**，重试后仍无结果才如实告知」

## 兼容性

- 生物医学路径不受影响（回归验证：某非编码 RNA 实验室仍正常命中 15 + 13 篇）
- 工具数保持 20（种子策略作为 `search_papers` 的第 4 源，不新增工具）
